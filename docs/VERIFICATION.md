# 验证记录

2026-10-26，1.2.0 独立构建在 Windows 11 / 150% 缩放 / Windows PowerShell 5.1 / PSReadLine 2.0 / Python 3.13 上验证。

## 1.2.0 原生菜单与 DPI

- 改造前只读测得：AKKO 为 System Aware，SoundKeeper 和 SteamMonitorTray 为 DPI Unaware；SoundKeeper 的 pystray Windows 后端已经使用原生菜单。两个参考项目未修改。
- 新 UI 构建显式面向 .NET Framework 4.8，启用 Common Controls v6 和 Per-Monitor V2。正式程序和测试程序使用相同清单、运行配置与 UI 程序集。
- 在实际窗口上验证 Per-Monitor V2 上下文（不仅检查配置文本），当前菜单宿主 DPI 为 144；宿主保持隐藏。
- 通过原生 API 检查子菜单、Unicode、字面量 &、勾选、禁用及取消命令；循环创建/销毁 200 份菜单树，USER 资源未持续增长。
- UI Automation 只操作本地测试进程的原生菜单：验证真实选择返回后菜单句柄已释放，命令仅执行一次。
- FakeMonitor 最小化后打开真实原生主菜单和配置子菜单，后台状态变化期间菜单保持展开；下一份快照读取新状态。通过实际子菜单的“停止监测”完成真实 Ctrl+C 清理。
- 六种语言的设置窗口实际创建于 150% DPI，检查说明文本和按钮尺寸，并用虚构路径保存布局预览；修复法语保存按钮裁切，保存/取消改为按文字自动调整宽度。
- 构建支持独立输出目录，打包使用独立暂存构建；新便携包包含必须与 EXE 配套的 SteamMonitorTray.exe.config，白名单增加至 11 个运行文件。
- Windows PowerShell 5.1 下完成独立构建和 1.2.0 打包，源文件/暂存区/历史及实际 ZIP 扫描通过。用户正常退出旧版后，已将扫描过的包内六个运行文件逐字节同步至 bin，EXE 文件版本为 1.2.0.0；未自动启动真实监测。

目前仅有单显示器 150% 的实际 DPI 验证。100%、125%、200% 以及不同缩放显示器之间的真实视觉效果尚未实测，不将程序化布局检查等同于这些环境的验证。桌面 computer-use 工具拒绝访问测试窗口（Computer Use was not approved to use tests），因此未完成三个真实托盘菜单的人工式视觉并排比较；原生控件交互测试与 DPI 查询已通过。用户可在交互预览或更新后检查菜单清晰度、Esc 和点击外部关闭行为。

## 自动化验证

- .NET Framework 编译成功，启用编译警告即错误。
- 配置、隐私、翻译资源与双语文档单元测试：12 项通过。
- 原生集成测试使用本地 FakeMonitor，不调用真实 Steam 或 Discord。
- 创建两个独立控制台时均不可见，未收到对应窗口的初始显示事件。
- 显示/隐藏保留同一会话；测试显示窗口时不激活焦点。
- 收到真实 `CTRL_C_EVENT`，完成清理后回到原有 PowerShell 提示符。
- 停止一个实例不影响另一个。
- 有未提交输入时拒绝托盘启动，原输入保持可执行。
- 可在提示符执行普通 PowerShell 命令及手动输入 `steam_monitor`。
- 手动 Ctrl+C、非零退出码与手动 `exit` 均正确回报状态。
- 托盘管理器实际执行初始启动加三次重试，然后显示异常。
- 手动停止后不会自动重新启动。
- 复现并修复最小化到托盘后，重复隐藏通知使右键菜单迅速消失的问题。
- 最小化只发送一次隐藏通知；原生主菜单与子菜单展开时不因后台刷新关闭，下次打开时读取最新状态。
- 通过最小化后的托盘菜单停止监测，测试程序收到真实 Ctrl+C 并完成清理。
- 自启动菜单使用勾选项，按照要求排列设置菜单。
- 语言菜单位于窗口隐藏设置下方，包含自动及六种界面语言；验证语言持久化、旧配置兼容、即时切换和阿拉伯语方向，用户路径与名称不被翻译。
- 退出菜单简化为“退出程序”，自动执行原有优雅停止；中文和英文 README 均明确说明不需要先手动按 Ctrl+C。
- 首页使用互斥语言折叠区，英文在前且默认展开，中文在后且默认收起；顶部提供简体中文入口。独立英文版同步嵌入首页，仅调整页内导航链接；链接和翻译格式占位符由离线测试检查。
- 中英文页头的语言栏紧接项目标题，位于项目简介与功能概述之前；使用三级标题放大，GitHub 样式预览中为 20px，正文为 16px。
- 保留同页互斥折叠，中文展开标题改为“简体中文 · 点击展开中文说明”，使用二级标题放大至 GitHub 样式下的 24px；预览验证在中文锚点已存在、中文仍收起的状态下，直接点击大标题可展开中文。
- 完整 README 通过 GitHub Markdown API 渲染，在独立 Edge 本地预览中检查英文默认和正常双向切换；仅预览未推送的文档，不修改远程仓库。
- 已知限制：带语言锚点的页面按 F5 后，折叠状态可能恢复默认，而地址仍保留原锚点；此时同一链接可能不再触发展开。可直接使用对应语言标题的三角箭头。此场景已在实际公开首页复现，不能把正常切换测试视为刷新后状态保留的保证。
- 在隔离测试目录和独立测试注册表键中验证注册、取消注册、重复注册、禁用提醒、外部状态刷新和未知格式；不改动真实启动项或真实 StartupApproved 值。
- 管理器、PowerShell 和会话宿主通过正常流程退出，无强制终止调用。
- 静态扫描覆盖源码、暂存区、可达历史；发布时额外扫描 ZIP。

集成测试需要普通交互式 Windows 会话。受限沙箱可能阻断控制台或管道，不应把沙箱连接超时当作普通桌面功能通过。

## 仍需用户在真实登录周期检查

任务管理器中的启用/禁用和下一次真实登录启动行为，需要在用户愿意注销或重新登录时完成；自动测试不会注销或重启电脑。快捷方式目标、参数与工作目录可直接检查，不能替代登录验收。

自动化未捕获显示事件是无闪现的程序级证据；不同 Windows 更新、终端设置和显示环境下仍建议进行人工观察。
